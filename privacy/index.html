Architect Radio Publisher: Privacy Policy

Effective date: 11 October 2026

Back to Architect Radio

Architect Radio Publisher ("the tool") is an internal command-line tool that {{LEGAL_NAME}} ("I") uses to publish my own videos to my own YouTube channel. It has one user: me.

YouTube API Services. The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). Google's handling of your data is described in the Google Privacy Policy (https://www.google.com/policies/privacy).

What the tool accesses. With my permission, given once through Google's OAuth consent screen, the tool accesses my own YouTube channel's id and title; the metadata of my own videos (title, description, tags, privacy status, captions, thumbnails and playlist membership); and my own channel's analytics and reach reports (for example views, thumbnail impressions and click-through rate). It does not access anyone else's channel or data.

How it uses the data. The tool uses this data only to upload my videos, confirm that each upload was saved correctly, and help me understand how my own videos perform.

Where the data is stored and for how long. All data stays on my own computer. OAuth tokens are stored in a private file that only my user account can read. Video ids, report job ids and downloaded reports are stored in my project folders. There is no server and no cloud database. The data is kept while my authorization is in effect. If authorization is revoked, or deletion is requested, I delete the stored YouTube data and tokens within 7 days.

Sharing. The data is not sold, shared or disclosed to any third party, inside or outside my business.

Cookies and advertising. The tool does not store or read cookies on any device, and it does not allow any third party to serve content or advertising.

Revoking access. You can revoke the tool's access to YouTube data at any time at https://security.google.com/settings/security/permissions.

Contact. For questions, or to request deletion, email {{CONTACT_EMAIL}}.
